# Prashant Singh — Cloud & DevOps Portfolio

A responsive React, TypeScript, and Vite portfolio site for Prashant Singh.

## Run locally

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

GitHub Actions builds and deploys the site to GitHub Pages when changes are pushed to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
